AppFeedback

AppFeedback class

Static utility class for all sound effects and haptic feedback.

All playback methods check User.isSoundEnabled or User.isVibrationEnabled before performing any action, ensuring user preferences are always respected.

Fields:

  • _player: the single shared AudioPlayer instance for all sound effects
